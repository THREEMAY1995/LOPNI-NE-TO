# Лопни не то!

Бесплатная браузерная мини-игра на HTML, CSS и JavaScript.

## Запуск на компьютере
1. Распакуйте архив.
2. Откройте `index.html` в современном браузере.

Для теста через локальный сервер можно использовать расширение Live Server в Visual Studio Code.

## Публикация на Cloudflare Pages
1. Создайте репозиторий на GitHub и загрузите в него `index.html`, `style.css`, `game.js`.
2. Откройте Cloudflare Dashboard → Workers & Pages → Create → Pages.
3. Подключите репозиторий.
4. Для простого статического сайта выберите отсутствие команды сборки, а каталог публикации укажите как корень проекта.
5. Нажмите Deploy и откройте выданный адрес `*.pages.dev`.

Интерфейс Cloudflare может меняться; если предложенные пункты называются иначе, выберите подключение Git-репозитория и публикацию статических файлов.

## Монетизация: порядок действий
1. Сначала опубликуйте игру и проверьте её на телефонах.
2. Для добровольной поддержки можно создать страницу проекта на itch.io. Укажите бесплатную игру и включите оплату по желанию, если эта функция доступна для аккаунта и страны.
3. Не вставляйте выдуманную ссылку на оплату: добавляйте только реальную ссылку, созданную в выбранном сервисе.
4. Рекламную сеть подключайте только после появления стабильной аудитории и проверки требований сети к сайту и аудитории.
5. Игра рассчитана в том числе на детей. До подключения рекламы изучите правила для детской аудитории, согласия и приватности. Не добавляйте поведенческую рекламу или навязчивые объявления.
6. Для продаж цифровых наборов выберите платёжный сервис, который работает в вашей стране, проверьте комиссии, налоги и правила возврата.

## Что уже реализовано
- 30-секундный раунд
- Цветные и опасные пузыри
- Очки и бонус за серию
- Локальное сохранение рекорда
- Звуковые эффекты с выключателем
- Перезапуск и системное меню «Поделиться»
- Адаптация под мобильный экран

## Ограничения первой версии
- Нет сервера, аккаунтов и онлайн-таблицы рекордов.
- Рекорд хранится в браузере конкретного устройства.
- Нет рекламного SDK и встроенных покупок.
- Google Fonts подключается внешним запросом; при отсутствии сети используются системные шрифты.
